# 🎯 CV 目标检测数据集格式转换工具箱 (Dataset Format Converter)

这是一个轻量级、高鲁棒性、**零第三方依赖**的 Python 工具箱。专门用于在计算机视觉（CV）目标检测任务中，实现 **PASCAL VOC、MS COCO、YOLO** 三大主流数据集格式的互相转换。

无论是用于模型训练（如 YOLOv8, MMDetection, Detectron2）还是用于模型评估（pycocotools），本工具箱都能帮你快速打通数据壁垒。

## ✨ 核心特性

* **🚀 零依赖开箱即用**：只使用 Python 原生内置库 (`os`, `json`, `xml.etree.ElementTree`)，无需 `pip install` 任何杂乱的第三方包（仅 `yolo2` 系列脚本需要 `Pillow` 读取图像尺寸）。
* **🛡️ 工业级鲁棒性**：内置数据清洗机制。自动拦截并跳过尺寸为0、坐标越界、或是没有 `<size>` 标签的损坏脏数据，告别转换中途崩溃。
* **🧠 智能背景图处理**：在转换 YOLO 格式时，智能识别纯背景图片（无目标的负样本），并生成对应的空白 `.txt` 文件，严格对齐训练标准。
* **⚡ 极速内存优化**：在处理庞大的 COCO `.json` 文件时，采用 `collections.defaultdict` 进行哈希降维分组，几十万个目标的转换仅需数秒。

---

## 📂 工具箱目录

本仓库包含以下 4 个核心转换脚本，满足你在任何场景下的双向转换需求：

| 脚本名称 | 功能描述 | 核心应用场景 |
| :--- | :--- | :--- |
| `voc2yolo.py` | **VOC -> YOLO** | 拿到传统公开数据集，准备喂给 YOLO 家族模型训练。 |
| `voc2coco.py` | **VOC -> COCO** | 拿到传统公开数据集，准备使用 DETR 或 Mask R-CNN 训练。 |
| `coco2yolo.py` | **COCO -> YOLO** | 将庞大的 COCO 数据库“拆包”，生成 YOLO 极致轻量的训练标签。 |
| `coco2voc.py` | **COCO -> VOC** | 将 JSON 数据库逆向解析为直观的 XML 档案，方便使用传统软件查看。 |

*(注：由于 YOLO 格式极度精简，缺乏绝对尺寸和元数据，不推荐将 YOLO 逆向转换为其他格式。如确有需要，需搭配原始图像文件自行推算)*

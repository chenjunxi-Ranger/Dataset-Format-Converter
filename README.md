# 🎯 CV 目标检测数据集格式转换工具箱 (Dataset Format Converter)

这是一个轻量级、高鲁棒性的 Python 工具箱。专门用于在计算机视觉（CV）目标检测任务中，实现 **PASCAL VOC、MS COCO、YOLO** 三大主流数据集格式的**全向互转（包含 6 大核心脚本）**。

无论是用于模型训练（如 YOLOv8, MMDetection, Detectron2），还是用于模型评估、数据清洗统计（如 pycocotools），本工具箱都能帮你快速打通数据壁垒。

---

## ✨ 核心特性

* **🚀 极简依赖开箱即用**：主体框架仅使用 Python 原生内置库 (`os`, `json`, `xml.etree.ElementTree`, `collections`)。*注：仅 YOLO 逆向转换脚本需要 `Pillow` 库辅助读取图像尺寸。*
* **🛡️ 工业级鲁棒性**：内置数据清洗机制。自动拦截并跳过尺寸为 0、坐标越界、或是缺失 `<size>` 标签的损坏脏数据，告别转换中途崩溃。
* **🧠 智能背景图处理**：在互相转换时，智能识别纯背景图片（无目标的负样本），并生成/保留对应的空白标签文件，严格对齐工业界训练标准。
* **⚡ 极速内存优化**：在处理庞大的 COCO `.json` 文件时，采用 `collections.defaultdict` 进行哈希降维分组，几十万个目标的转换仅需数秒。

---

## 📂 工具箱目录 (支持 6 种双向转换)

本仓库包含了满足你所有转换需求的 6 个核心脚本：

| 脚本名称 | 功能描述 | 核心应用场景 |
| :--- | :--- | :--- |
| `voc2yolo.py` | **VOC -> YOLO** | 拿到传统公开数据集，转换为相对坐标，准备喂给 YOLO 家族模型训练。 |
| `voc2coco.py` | **VOC -> COCO** | 拿到传统公开数据集，打包为 JSON，准备使用 DETR 或 Mask R-CNN 训练。 |
| `coco2yolo.py` | **COCO -> YOLO** | 将庞大的 COCO 数据库“拆包”，提取生成 YOLO 极致轻量的 `.txt` 训练标签。 |
| `coco2voc.py` | **COCO -> VOC** | 将 JSON 数据库逆向解析为直观的 XML 档案，方便使用传统桌面标注软件查看。 |
| `yolo2coco.py` | **YOLO -> COCO** | 将零散的 YOLO 标签整合成标准的关系型 JSON 数据库，便于使用 `pycocotools` 评估 mAP。 |
| `yolo2voc.py` | **YOLO -> VOC** | 还原归一化坐标为绝对像素坐标，恢复传统数据结构。 |

---

## ⚠️ 特别注意：关于 YOLO 的逆向转换 (YOLO -> 其他)

YOLO 格式出于极致轻量化的考量，**丢失了图像的绝对宽高尺寸**，只保留了 `0~1` 的归一化比例。因此，在使用 `yolo2coco.py` 和 `yolo2voc.py` 时，**必须满足以下两个条件**：
1. **必须准备原始图片**：你需要准备一个包含原始图片的文件夹（如 `images/`），脚本需要读取图片的真实宽高才能还原绝对坐标。
2. **安装 Pillow 库**：请确保你的 Python 环境安装了图像处理库：
```bash
pip install Pillow
```

## 🛠️ 快速上手指南
所有脚本的使用逻辑保持高度一致，只需简单三步：

### 1. 准备目录结构
建议在脚本同级目录下，按照以下格式准备好你的数据文件夹（具体文件夹名称可在代码顶部修改）：
```
Dataset-Format-Converter/
├── Annotations/    # 存放原始的 .xml 文件
├── images/         # 存放原始的 .jpg/.png 图片 (YOLO逆向转换必需)
├── coco/           # 存放原始的 .json 文件
├── yolo/           # 存放原始的 .txt 文件
├── ... (脚本文件)
```

### 2. 修改类别配置 (最重要的一步！)
用任何代码编辑器打开你需要运行的 .py 脚本，找到文件最顶部的 CLASSES 列表：
```python
# ==========================================
# ⚠️ 必须修改的配置区域
# ==========================================
CLASSES = ['ship', 'airplane', 'car'] # 替换为你真实的数据集类别
```
注意：请严格确保这里填写的类别名称与你原始数据集中的标签大小写完全一致，并且顺序极其重要（这决定了生成的类别 ID）！

### 3. 一键运行
在终端中执行对应的脚本（以 VOC 转 YOLO 为例）：
```bash
python voc2yolo.py
```
运行结束后，脚本会自动在当前目录下创建输出文件夹（如 labels 或 COCO_Output），并生成转换后的文件。控制台会打印出详细的转换统计和【类别 ID 映射关系】。
